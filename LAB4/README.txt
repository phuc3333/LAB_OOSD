E-SHOPPING SYSTEM
=================

1. GIOI THIEU
-------------
e-SHOPPING la he thong mua sam truc tuyen duoc xay dung bang C# Windows Forms va SQL Server.

He thong duoc thiet ke de minh hoa cac chuc nang co ban cua mot ung dung ban hang truc tuyen.

2. CONG NGHE SU DUNG
--------------------
- Ngon ngu: C#
- Giao dien: Windows Forms
- Nen tang: .NET Framework 4.7.2
- Co so du lieu: Microsoft SQL Server
- Cong cu phat trien: Visual Studio
- Quan ly ma nguon: Git va GitHub

3. CHUC NANG
------------
- Quan ly danh muc san pham
- Hien thi danh sach san pham
- Them san pham moi
- Luu du lieu san pham vao SQL Server
- Tai lai danh sach sau khi them san pham

5. HUONG DAN CAI DAT
--------------------
Buoc 1: Cai dat Visual Studio va SQL Server.
Buoc 2: Mo file solution EShopping.sln bang Visual Studio.
Buoc 3: Tao database EShopping tren SQL Server.
Buoc 4: Chay cac lenh SQL de tao cac bang va du lieu mau.
Buoc 5: Cap nhat chuoi ket noi trong App.config.
Vi du: Data Source=.;Initial Catalog=EShopping;Integrated Security=True
Buoc 6: Build va chay ung dung bang Visual Studio.

6. CAU HINH KET NOI
-------------------
Chuoi ket noi duoc khai bao trong App.config.
Khong dua mat khau hoac thong tin nhay cam vao repository cong khai.
